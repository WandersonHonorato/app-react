## ▶️ Como executar

Clone o repositório:

```bash
git clone https://github.com/WandersonHonorato/app-react.git
````
Entre na pasta:
```bash
cd app-react
````
Instale as dependências:
```bash
npm install
````
Execute o projeto:
```bash
npm run dev
````
